## 接入前需要处理的事项

1. **真实连接待验证。** 在自己的 IDEA 运行配置设置 DB_URL、DB_USER、DB_PASSWORD，运行 --check-db，确认自己的目标数据库及 public schema。
2. **Q7 错误码待对齐。** 仓库 Task3_247.sql 的自定义 RAISE EXCEPTION 没有设置合同要求的 ERRCODE，默认 P0001 会被映射为 DB_ERROR。接入前需将无效输入、目标缺失、歧义分别对齐 22023、P0002、P0003，并同步 A 的正式导入。
3. **DDL 名称需统一引用。** 旧约定写 schema.sql；当前实际文件是 create_table.sql。本轮没有复制第二份 DDL，也没有更改原文件。
4. **业务实现与实库事务验收待完成。** 尤其是行锁、连续站序、批量失败无部分数据、删除受引用对象、改线后邻站及路径刷新，不能以当前测试替身代替 PostgreSQL 验收。
5. **票价规则仍待确认。** 固定接口和未配置状态不会产生真实票价。
6. **Java 17 运行环境待最终验证。** 本次是在 JDK 21 上按 release 17 编译和测试，未在独立 JDK 17 运行时复测。
7. **最终打包待确定。** 当前生成普通 jar；通过 IDEA/Maven exec 运行时带上依赖。直接 java -jar 普通 jar 不会包含 pgJDBC。
8. **同步后保持公共合同一致。** 双方使用同一份 DTO 和 Service 接口；数据库连接配置由各自提供。
