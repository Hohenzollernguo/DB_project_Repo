# 线路名称更新：实现与验证

日期：2026-11-05。范围：`LineService.update(long lineId, LineDraft input)`，通过 CLI、Swing 和 JDBC 修改一条已有线路的完整中英文名。

2026-11-09 更新了用户选线流程。用户输入线路编号，例如 `13`，程序查询候选线路，再将选中记录的内部 `line_id` 传给更新服务。下文“本次执行记录”保留 2026-11-05 的历史结果，编号选线的本轮验证单独记录在“编号选线回归验证”。

## 行为与职责

```text
CLI 菜单 2 / Swing 线路修改表单
  → 输入线路编号，调用 LineService.search
  → 单条自动选中，多条列出 ID 和中英文名供选择
  → 取得选中记录的 lineId，填写完整的新中英文名
  → JdbcLineService.update：校验 ID、校验并规范化名称
  → Transactions.write：为本次请求提供独立连接
  → LineDao.updateName：绑定参数，执行一条 UPDATE
  → Service：检查影响行数，构造 LineView
  → Transactions：提交并关闭连接，再返回结果；失败则回滚
```

线路更新是全量资料替换，两种名称必须一起提供。名称去除首尾空白，保留内部空格、大小写、标点和斜杠。拒绝非正数 ID、null 输入、null/空白名称和 PostgreSQL TEXT 不支持的空字符。参数错误在打开数据库连接前返回 `INVALID_INPUT`。

DAO 沿用现有 `updateName(Connection, long, LineDraft)`，SQL 只修改 `public.metro_line` 的 `chinese_name` 和 `english_name`，不修改 `line_id`。用户输入通过三个 `?` 绑定。DAO 关闭自己创建的 PreparedStatement，不提交、回滚或关闭共享 Connection。

Service 通过 UPDATE 影响行数直接判断目标：0 行抛 `NOT_FOUND`，1 行返回新 `LineView`，异常行数抛 `DB_ERROR` 并回滚。数据库中两种名称各自的 UNIQUE 约束负责拒绝重名；沿用 `SqlErrors` 的 SQLSTATE 23505 → `DUPLICATE` 转换，避免“先查重再更新”的并发窗口。写回原名称仍是一次成功更新。

交互层先按编号查询并选择目标。写事务中的 UPDATE 仍按选中记录的主键定位，由影响行数判断目标在提交修改时是否存在。查询后目标若被其他请求删除，更新返回 `NOT_FOUND`。返回对象使用同一次 UPDATE 的 ID 和规范化名称，事务提交成功后调用方取得结果。

## 线路编号与候选选择

- CLI 和 Swing 的初始输入均为线路编号，去除首尾空白后接受 `[1-9][0-9]*`。
- 编号按完整数字匹配。输入 `13` 查询 `Line 13` 及其分期、延伸段等同编号记录。输入 `1` 查询编号为 1 的记录。
- 查询无匹配时显示编号和未找到提示，结束本次修改。单条匹配时自动选中其真实 `line_id`。
- 多条匹配时列出每条线路的内部 ID、中英文名。CLI 要求输入列表中的 ID，空行取消，非法或列表外 ID 返回 `INVALID_INPUT`。Swing 使用显示 ID 和名称的候选下拉框，初始保持未选择，选中一条后启用保存。
- Swing 选定线路后填入当前中英文名。修改线路编号会清空原候选并禁用保存，查询失败也会清空旧候选。查询、保存均通过后台线程执行，执行期间禁用重复操作。
- 保存成功后使候选选择失效，下次修改重新查询。保存发生业务错误时保留输入和选中线路，供用户修正后重试。

## 手工验收

在 IDEA 运行配置设置 `DB_URL`、`DB_USER`、`DB_PASSWORD`，先用 `--check-db` 核对目标数据库。模板和本地 `config/db.env` 不会被程序自动加载，仍需在启动环境中设置变量。本次读取本地配置仅用于测试，真实配置保存在已被 Git 忽略的 `config/db.env`。

CLI 默认启动，选择 `2`，输入线路编号。多条匹配时查看候选 ID 和名称，输入目标 ID，再输入新中文名和新英文名。仅一条匹配时直接进入新名称输入。Swing 使用 `--gui`，点击“修改线路名称”，输入编号并点击“查询线路”，选定具体线路后编辑中英文名并保存。两者都展示成功后的 ID 和名称，或统一的错误码及安全错误消息。

| 场景 | 预期 |
|---|---|
| 已有线路、中英文名均合法 | 名称一起提交，ID 和站线关系保留 |
| 输入编号 13，唯一候选的内部 ID 为 42 | 更新 ID=42 的记录 |
| 编号 13 有多条分期线路 | 列出各条 ID 和名称，显式选择后只更新选中记录 |
| 编号无匹配 | 显示未找到，无写入 |
| CLI 选择列表外 ID 或取消 | 错误反馈或取消，无写入 |
| Swing 查询后修改编号 | 清空旧候选，重新查询后才能保存 |
| 名称首尾包含空白 | 存储与返回值均去除首尾空白 |
| 非法 ID、缺失或空白名称 | INVALID_INPUT，数据库无修改 |
| 合法但不存在的 ID | NOT_FOUND |
| 中文名或英文名与另一条线路重复 | DUPLICATE，原中英文名都保留 |
| 原样保存当前名称 | 成功 |
| 名称包含引号或看似 SQL 的文本 | 按字面量存储，SQL 结构不受影响 |
| SQL 执行失败或提交失败 | 抛出错误并回滚，界面不显示修改成功 |
